# Atividade 08 - Semana da arte moderna

Este projeto consiste no desenvolvimento de uma página web sobre a obra Soror Dolorosa, do escultor Victor Brecheret. O site apresenta informações sobre a escultura, suas características, seu significado e sua relação com a Semana de Arte Moderna de 1922.

Para o desenvolvimento da página, foram utilizados HTML e CSS, explorando diferentes fontes e uma paleta de cores escolhida para criar uma identidade visual harmoniosa e agradável. O projeto teve como objetivo praticar os conhecimentos de desenvolvimento web e demonstrar como a combinação de cores, fontes e organização dos elementos podem contribuir para a apresentação de informações artísticas.
